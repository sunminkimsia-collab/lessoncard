# 레슨카드 · LessonCard

> 레슨 후 30초, 학부모님께 보내는 레슨 카드
> 피아노·음악 강사를 위한 **학부모 피드백 카드 생성기** (1차 프로토타입)

---

## 1. 무엇을 하는 서비스인가

레슨이 끝난 직후, 선생님이 오늘의 곡과 잘한 점만 적으면
학부모 카카오톡에 바로 보낼 수 있는 **1080×1350px 세로형 카드 PNG**가 만들어집니다.

- **누구를 위해**: 피아노·바이올린·성악 등 1:1 레슨을 하는 개인 강사, 작은 음악 스튜디오, 학원 원장
- **무엇이 불편했나**: 매주 같은 말로 카톡을 쓰는 반복 노동, 학부모가 "오늘 뭐 배웠는지" 알기 어려움, 학원별 리포트 양식 부재
- **무엇이 달라지나**: 입력 30초 → 카드 저장 → 카톡 사진 전송. 학부모가 저장·공유하고 싶은 품질의 카드가 남습니다

카드는 `1080×1350`(4:5) 비율로, 카카오톡 사진·인스타그램 피드·문자 어디에 붙여도 잘리지 않습니다.
폰에서는 화면 하단 고정 버튼으로 바로 저장하고, 카드를 탭하면 크게 볼 수 있습니다.

## 2. 핵심 기능

| 기능 | 설명 |
| --- | --- |
| **30초 입력 폼** | 스튜디오·선생님 이름, 학생 이름, 날짜·회차, 오늘의 곡/진도, 잘한 점, 연습 미션, 다음 레슨 한마디 |
| **원클릭 예시** | `예시 채우기` 버튼으로 실제 피아노 레슨 예시(쇼팽 왈츠 Op.64 No.2 · 위신원 학생)가 즉시 채워집니다. 처음 방문한 강사도 바로 결과물을 볼 수 있음 |
| **잘한 점 태그칩** | 과목·악기 탭 4종(**피아노 / 보컬·성악 / 현악·관악 / 공통·예체능**)별 8개 프리셋 원클릭 선택 + 직접 입력 추가. 최대 4개. 탭을 바꿔도 이미 고른 태그는 그대로 남고 추천 목록만 전환되며, 마지막으로 고른 탭은 localStorage에 기억 |
| **한마디 원클릭 문구** | `다음 레슨 안내 · 한마디` 입력란 바로 위 문구 칩 5종(잘했을 때 / 조금 부족할 때 / 발표회·콩쿠르 전 / 첫 달·초보 응원 / 일정·보강 안내). 누르면 110자 이내 문장이 즉시 채워지고 글자 수·실시간 카드 미리보기가 바로 반영. 직접 고치면 칩 강조가 해제 |
| **카드 테마 3종** | ① 크림 클래식(따뜻한 아이보리) ② 딥 네이비 콘서트 ③ 로즈 우드 |
| **실시간 미리보기** | 타자를 칠 때마다 카드가 다시 그려집니다(Canvas). 카드 탭 → 확대 보기 |
| **고화질 PNG 저장** | Canvas 2배 슈퍼샘플링으로 그린 뒤 `1080×1350` 정확한 크기로 내려받습니다. 글자 잘림 없음(자동 축소·말줄임 처리) |
| **공유하기(모바일)** | 카드를 OS 공유 시트로 바로 전달(Web Share API). 안드로이드 크롬에서 카카오톡 선택 → 사진 전송 |
| **카톡용 텍스트 복사** | 이미지와 함께 보낼 수 있는 텍스트 요약을 클립보드로 복사 |
| **내 학생 (누적 기록)** | `PNG 저장`·`공유하기`·`카톡용 텍스트 복사` 또는 `학생 기록 저장`을 누를 때마다 학생 이름 기준으로 최신 레슨 내용(스튜디오·선생님·회차·곡·태그·미션·한마디)을 localStorage에 쌓습니다. 폼 상단 칩을 누르면 직전 기록이 즉시 불러와지고 **회차 숫자가 +1**(12회차→13회차)·**레슨 날짜는 오늘**로 세팅되며, `+ 새 학생`으로 빈 폼에서 시작, 칩의 `×`로 삭제(토스트에서 `되돌리기`). 첫 방문자는 샘플 학생 2명(`위신원 · 12회차`, `김서연 · 4회차`)으로 바로 체험 |
| **학원 로고** | 스튜디오 이름 아래 `학원 로고 (선택)`에서 PNG/JPG 업로드 → 긴 변 420px로 리사이즈해 localStorage 보관, 카드 좌측 상단 스튜디오 이름 옆에 비율 유지해 `drawImage`로 렌더(DataURL이라 캔버스 taint 없음). `로고 바꾸기`·`삭제` 제공, 라벨 옆 `Pro 미리체험` 태그 |
| **자동 저장** | 입력값·테마를 브라우저 localStorage에 저장. 새로고침해도 이어서 작성 |
| **수익화 UI** | 헤더 플랜 배지(무료 3회) · Pro 업그레이드 미리보기 모달 |
| **사용법 안내** | 헤더 `사용법` 버튼 → 3단계 초간단 가이드 모달(입력 · 테마/미리보기 · 저장/카톡 전송 + 저장 위치·홈 화면 추가 팁). 모달에서 `예시로 채워보기`로 바로 체험 가능 |

### 단축키
- `Ctrl/⌘ + S` : PNG 저장
- `Esc` : 모달·확대 보기 닫기

## 5. 실행 방법

### 로컬에서 바로 열기
파일을 더블클릭해도 되지만, 폰트 로딩·클립보드를 정확히 확인하려면 정적 서버를 권합니다.

```bash
cd documents/레슨피드백-웹앱
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### Vercel
1. https://vercel.com/new 에서 이 폴더를 드래그&드롭 (또는 Git 저장소 연결)
2. Framework Preset: **Other**, Build Command 없음, Output Directory: `.`
3. Deploy → `https://<프로젝트>.vercel.app`

```bash
# CLI로 배포하는 경우
npx vercel --prod documents/레슨피드백-웹앱
```

### GitHub Pages
```bash
cd documents/레슨피드백-웹앱
git init && git add . && git commit -m "LessonCard prototype"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```
저장소 → **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`** → 저장.
`https://<계정>.github.io/<저장소>/` 에서 열립니다. (`index.html`이 루트에 있으므로 그대로 동작)

### Next.js로 이식할 때
- `index.html`의 `<style>` → `app/globals.css`(또는 CSS Modules), 마크업 → `app/page.tsx`
- 카드 렌더러(`drawCard`, `wrapText`, `drawTracked`, `THEMES`)는 `lib/renderCard.ts`로 그대로 옮길 수 있습니다. DOM에 의존하지 않고 `canvas`와 데이터만 받습니다.
- 폼 값은 `useState`, 렌더는 `useEffect` + `requestAnimationFrame` 디바운스로 연결하면 됩니다.
- 저장(PNG)은 `canvas.toBlob()` → `URL.createObjectURL()` → `<a download>`; 서버 저장이 필요하면 같은 Blob을 `fetch('/api/upload')`로 보내면 됩니다.

## 6. 구현 메모 (기술)

- **Canvas 2배 슈퍼샘플링**: 2160×2700으로 그린 뒤 1080×1350으로 다운스케일 → 작은 글자도 계단현상 없이 선명합니다.
- **글자 잘림 방지 3단계**
  1. 모든 텍스트는 어절 단위로 줄바꿈(`wrapText`)하고, 공백 없는 긴 문자열은 폭 기준으로 강제 분할
  2. 섹션별 최대 줄 수 제한 + 말줄임
  3. 전체 높이가 넘치면 최대 0.62배까지 자동 축소(레이아웃 재계산), 그래도 넘치면 섹션 최대 줄 수로 제한
- **폰트**: Noto Serif KR / Noto Sans KR / Cormorant Garamond(Google Fonts). `document.fonts.load()`로 필요한 굵기를 미리 로드한 뒤 렌더하고, `loadingdone` 이벤트에서 다시 그립니다. CDN이 막히면 시스템 폰트로 폴백.
- **테마**: 색 토큰만 바꿔 같은 레이아웃을 3가지 분위기로 렌더(배경 그라데이션·광원·비네트 포함).
- **자간**: 한글은 canvas `letterSpacing` 지원이 브라우저마다 달라, 글자 단위로 직접 배치해 어디서나 동일하게 보이도록 했습니다.
- **반응형**: 1000px 이하에서 1열 + 미리보기 우선 배치 + 하단 고정 저장 바.
- **저장 키(localStorage)**: `lessoncard.draft.v1`(작성 중 폼) · `lessoncard.students.v1`(학생별 최근 기록 배열) · `lessoncard.logo.v1`(로고 DataURL·파일명) · `lessoncard.theme.v1` · `lessoncard.subject.v1`(잘한 점 과목·악기 탭) · `lessoncard.usage.v1`. 학생 기록은 이름 기준으로 최신 1건을 교체 저장하고 목록은 최근 저장순으로 정렬합니다.
- **과목 탭**: `SUBJECTS` 배열(피아노·보컬·성악·현악·관악·공통·예체능, 각 8개 프리셋)이 유일한 출처이고, `renderChips()`가 현재 탭 프리셋 + 이미 선택된 태그를 합쳐 그립니다. 그래서 탭을 바꿔도 고른 태그가 사라지지 않고 최대 4개 규칙도 그대로입니다.
- **한마디 문구**: `NOTE_PRESETS` 배열에서 칩을 만들고, 클릭 시 `textarea` 값을 교체한 뒤 `syncCounters()` · `scheduleRender(true)` · `saveDraft()`를 직접 호출합니다. 입력란을 직접 고치면 `input` 이벤트가 칩 강조를 풀어 줍니다.
- **로고**: 업로드 시 `<canvas>`로 긴 변 420px까지 줄여 PNG DataURL로 저장 → 카드에서는 헤더 높이에 맞춰 비율 유지 `drawImage`(모서리 7px 라운드 클립). 로컬 DataURL이라 `toBlob`/`toDataURL`이 막히지 않습니다.
