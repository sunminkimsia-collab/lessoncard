# 레슨카드 · LessonCard

> 레슨 후 30초, 학부모님께 보내는 레슨 카드
> 피아노·음악 강사를 위한 **학부모 피드백 · 레슨비 정산 · 발표회 팜플렛 카드 생성기** (프로토타입)

세 가지 카드가 한 앱에 들어 있습니다. 위쪽 탭에서 고르면 폼과 미리보기가 함께 바뀝니다.

| 카드 | 쓰는 순간 | 들어가는 것 |
| --- | --- | --- |
| **레슨 노트** | 매주 레슨 직후 | 오늘의 곱·잘한 점·연습 미션·한마디 |
| **레슨비 정산** *(NEW)* | 매달 말 | 진행 회차·수강료·할인/교재비·합계·납부 기한·입금 계좌·안내 |
| **발표회 팜플렛** *(NEW)* | 발표회 2~4주 전 | 공연 제목·부제·일시·장소·프로그램(연주자 — 곡명)·오시는 길 |

## 1. 무엇을 하는 서비스인가

레슨이 끝난 직후, 선생님이 오늘의 곡과 잘한 점만 적으면
학부모 카카오톡에 바로 보낼 수 있는 **1080×1350px 세로형 카드 PNG**가 만들어집니다.

- **누구를 위해**: 피아노·바이올린·성악 등 1:1 레슨을 하는 개인 강사, 작은 음악 스튜디오, 학원 원장
- **무엇이 불편했나**: 매주 같은 말로 카톡을 쓰는 반복 노동, 학부모가 "오늘 뭐 배웠는지" 알기 어려움, 학원별 리포트 양식 부재
- **무엇이 달라지나**: 입력 30초 → 카드 저장 → 카톡 사진 전송. 학부모가 저장·공유하고 싶은 품질의 카드가 남습니다

카드는 `1080×1350`(4:5) 비율로, 카카오톡 사진·인스타그램 피드·문자 어디에 붙여도 잘리지 않습니다.
폰에서는 화면 하단 고정 버튼으로 바로 저장하고, 카드를 탭하면 크게 볼 수 있습니다.

## 2. 핵심 기능

| 기능 | 설명 |
| --- | --- |
| **카드 종류 3종 탭** | 폼 위 세그먼트 탭 **`레슨 노트` · `레슨비 정산` · `발표회 팜플렛`**. 탭을 누르면 폼·헤드라인·미리보기·카톡 문구가 함께 바뀌고, 마지막 선택은 localStorage에 기억됩니다. 세 카드 모두 **같은 3세트×9테마·학원 로고·PNG 저장·카톡 텍스트**를 그대로 씁니다 |
| **30초 입력 폼** | 스튜디오·선생님 이름, 학생 이름, 날짜·회차, 오늘의 곡/진도, 잘한 점, 연습 미션, 다음 레슨 한마디 |
| **🎧 녹음 들으며 시간 찍기** *(v12)* | 카톡으로 받은 학생 녹음·연주 영상(m4a·mp3·wav·mp4·mov)을 끌어다 놓으면 **서버 업로드 없이** 브라우저에서 바로 재생. 배속 `0.75x·1.0x·1.25x`, `-5초`/`+5초`, `📍 지금 시간 찍기` → `0:24 · 왼손 미→파`처럼 시간+메모가 목록에 쌓이고, 항목을 누르면 그 시간으로 점프해 재생. 빠른 태그 5종(음정 틀림·박자 밀림·왼손 주의·페달·강약), 수정·삭제(되돌리기)·직접 입력 지원. 타임스탬프가 1곳 이상이면 카드에 **`🎧 연습 체크` 블럭**이 9테마 모두에 들어가고, 0곳이면 기존 카드와 픽셀까지 동일 |
| **원클릭 예시** | `예시 채우기` 버튼으로 실제 피아노 레슨 예시(쇼팽 왈츠 Op.64 No.2 · 박하은 학생)가 즉시 채워집니다. 처음 방문한 강사도 바로 결과물을 볼 수 있음 |
| **잘한 점 태그칩** | 과목·악기 탭 4종(**피아노 / 보컬·성악 / 현악·관악 / 공통·예체능**)별 8개 프리셋 원클릭 선택 + 직접 입력 추가. 최대 4개. 탭을 바꿔도 이미 고른 태그는 그대로 남고 추천 목록만 전환되며, 마지막으로 고른 탭은 localStorage에 기억 |
| **한마디 원클릭 문구** | `다음 레슨 안내 · 한마디` 입력란 바로 위 문구 칩 5종(잘했을 때 / 조금 부족할 때 / 발표회·콩쿠르 전 / 첫 달·초보 응원 / 일정·보강 안내). 누르면 110자 이내 문장이 즉시 채워지고 글자 수·실시간 카드 미리보기가 바로 반영. 직접 고치면 칩 강조가 해제 |
| **카드 테마 9종 (3세트 · 세트마다 다른 템플릿)** | 미리보기 위 세그먼트 탭 **`Minimal` · `Cute` · `Classic`**(내부 키 `clean` · `cute` · `chic`) 아래에 세트별 테마 3종. 세 세트는 색만 다른 게 아니라 **레이아웃·서체·장식이 통째로 다른 템플릿**입니다. **깔끔** = 구조화된 그리드·1px 헤어라인·Noto Sans KR — 섹션마다 **번호가 붙은 네모칸 블럭**과 연습 미션 강조 블럭(퓨어 화이트 회색 판+검정 포인트 바 · 웜 리넨 가운데 레터헤드+아이보리 판(기본값) · 모던 슬레이트 도면 그리드+채움 칩+네이비 강조 판) / **귀여운** = 두꺼운 파스텔 프레임+점선 카드인카드·Jua·Gowun Dodum·벡터 음표/별/하트/구름·스티커 태그(블러쉬 로즈 리본 탭 · 클라우드 스카이 말풍선 미션 · 소프트 버터 메모지+마스킹 테이프) / **세련된** = 이중 금빛 프레임+코너 장식·중앙 정렬 리사이틀 프로그램·Noto Serif KR+Cormorant Garamond(포레스트 세이지 딥그린+샴페인 골드 · 딥 네이비 골드 포일 · 로즈 우드 로즈골드). 세트를 오가도 세트별 마지막 테마를 기억하고, 선택은 localStorage에 저장. **발표회 팜플렛 모드에서는 이 9종 대신 연주회 전용 4종 스타일**을 씁니다(아래 항목) |
| **실시간 미리보기** | 타자를 칠 때마다 카드가 다시 그려집니다(Canvas). 카드 탭 → 확대 보기 |
| **고화질 PNG 저장** | Canvas 2배 슈퍼샘플링으로 그린 뒤 `1080×1350` 정확한 크기로 내려받습니다. 글자 잘림 없음(자동 축소·말줄임 처리) |
| **공유하기(모바일)** | 카드를 OS 공유 시트로 바로 전달(Web Share API). 안드로이드 크롬에서 카카오톡 선택 → 사진 전송 |
| **카톡용 텍스트 복사** | 이미지와 함께 보낼 수 있는 텍스트 요약을 클립보드로 복사 |
| **내 학생 (누적 기록)** | `PNG 저장`·`공유하기`·`카톡용 텍스트 복사` 또는 `학생 기록 저장`을 누를 때마다 학생 이름 기준으로 최신 레슨 내용(스튜디오·선생님·회차·곡·태그·미션·한마디)을 localStorage에 쌓습니다. 폼 상단 칩을 누르면 직전 기록이 즉시 불러와지고 **회차 숫자가 +1**(12회차→13회차)·**레슨 날짜는 오늘**로 세팅되며, `+ 새 학생`으로 빈 폼에서 시작, 칩의 `×`로 삭제(토스트에서 `되돌리기`). 첫 방문자는 샘플 학생 2명(`박하은 · 12회차`, `한지우 · 4회차`)으로 바로 체험 |
| **학원 로고** | 스튜디오 이름 아래 `학원 로고 (선택)`에서 PNG/JPG 업로드 → 긴 변 420px로 리사이즈해 localStorage 보관. 카드에서는 세트별로 다르게 배치합니다 — 깔끔은 스튜디오명 왼쪽, 귀여운은 오른쪽 점선 스티커 판, 세련된은 상단 중앙(금빛 헤어라인 아래). 비율 유지 `drawImage`(DataURL이라 캔버스 taint 없음). `로고 바꾸기`·`삭제` 제공, 라벨 옆 `Pro 미리체험` 태그 |
| **자동 저장** | 입력값·테마를 브라우저 localStorage에 저장. 새로고침해도 이어서 작성 |
| **레슨비 정산 카드** | 보호자 호칭 · 정산 기간 · 납부 기한 · 수업 내역/회차 · 수업 날짜·결석/보강 메모 · **수강료(숫자만 치면 3자리 콤마)** · 할인/교재비(음수면 할인) · **합계 자동 계산** · 입금 계좌(은행·계좌번호·예금주) · 안내 한마디(정중·보강·교재비·형제할인 4종 문구 칩). 계좌는 한 번만 입력하면 `lessoncard.account.v1`에 저장돼 다음 달부터 자동으로 채워집니다. 깔끔은 헤어라인 장부(도트 리더), 귀여운은 총액 스티커+메모 계좌, 세련된은 금빛 장부로 그립니다. `예시 채우기` 버튼도 이 모드 전용 12월 정산 예시 |
| **발표회 팜플렛 카드** | 공연 제목 · 부제/주최(비우면 스튜디오 이름) · 일시 · 장소 · 프로그램/출연진(**한 줄에 `연주자 — 곡명`, 최대 8줄**, 줄 수 카운터) · 오시는 길/드리는 말씀(주차·꽃다발/사진·입장·감사 4종 문구 칩). 이 모드에서는 9종 테마 대신 **연주회 팜플렛 전용 스타일 4종**을 고릅니다 — **A 미드나잇 홀**(다크 네이비+골드 헤어라인·코너 장식·그랜드피아노 실루엣·`01~08` 점선 프로그램) / **B 샴페인 아치**(샴페인 페이퍼·이중 아치·로마숫자 `I~VIII` 프로그램) / **C 럭셔리 티켓**(본 화이트·티켓 스텁+반원 노치+절취선·`No./PROGRAM/PERFORMER` 에디토리얼 표) / **D 로즈골드**(펄 아이보리·실크 리본·2×2 프로그램 카드). 스타일은 `lessoncard.recitalStyle.v1`에 저장되고, 1~8줄·긴 제목·여러 줄 안내문에서도 글자 겹침·잘림 없이 자동으로 간격·크기를 맞춥니다. `예시 채우기` 버튼 포함 |
| **수익화 UI** | 헤더 플랜 배지(무료 3회) · Pro 업그레이드 미리보기 모달 |
| **사용법 안내** | 헤더 `사용법` 버튼 → 3단계 초간단 가이드 모달(입력 · 테마/미리보기 · 저장/카톡 전송 + 저장 위치·홈 화면 추가 팁). 모달에서 `예시로 채워보기`로 바로 체험 가능 |

## 6. 구현 메모 (기술)

- **Canvas 2배 슈퍼샘플링**: 2160×2700으로 그린 뒤 1080×1350으로 다운스케일 → 작은 글자도 계단현상 없이 선명합니다.
- **글자 잘림 방지 3단계**
  1. 모든 텍스트는 어절 단위로 줄바꿈(`wrapText`)하고, 공백 없는 긴 문자열은 폭 기준으로 강제 분할
  2. 섹션별 최대 줄 수 제한 + 말줄임
  3. 전체 높이가 넘치면 최대 0.62배까지 자동 축소(레이아웃 재계산), 그래도 넘치면 섹션 최대 줄 수로 제한
- **폰트**: Noto Sans KR(깔끔) / Jua·Gowun Dodum(귀여운) / Noto Serif KR·Cormorant Garamond(세련된) — Google Fonts 5종. `FONT_SPECS`에 세트별 실제 쓰는 크기·굵기를 넣고 `document.fonts.load()` → `document.fonts.ready` 뒤에 그립니다. Canvas는 폰트가 늦게 오면 첫 렌더에서 대체 글꼴로 그려지므로, `loadingdone` 이벤트와 0.9초·2.2초 재렌더로 한 번 더 보정합니다. CDN이 막히면 시스템 폰트로 폴백.
- **세트 = 템플릿**: `THEMES`의 `set` 값에 따라 서로 다른 렌더러가 통째로 갈아 끼워집니다 — `drawCleanCard`(그리드·레일·헤어라인·산세리프) / `drawCuteCard`(둥근 파스텔 프레임·점선 안쪽 테두리·벡터 장식·스티커·Jua) / `drawLuxCard`(이중 금빛 프레임·코너 플뢰롱·중앙 정렬·세리프). 각 렌더러는 `measure → 높이 넘치면 0.955·0.91…로 자동 축소 → 배치` 순서로 같은 규약을 지키고, `state.lastLayout`에 `{set, mode, top, scale, bottom, overflow}`를 돌려줍니다. 테마는 그 안에서 색·여백·칩 모양·이름 자간·미션 박스 형태(`panel`)만 바꿉니다.
- **발표회 팜플렛 = 별도 렌더러 4종**: `RECITAL_RENDERERS`가 `midnight` · `arch` · `ticket` · `ribbon` 네 함수로 갈립니다. 9종 테마와 달리 `THEMES` 토큰을 쓰지 않고, 각 스타일이 자기 색·여백·장식을 직접 그립니다(이중 프레임·코너 L자·모노그램 엠블럼·그랜드피아노 `Path2D` 실루엣·이중 아치·티켓 노치/절취선·실크 리본·2열 프로그램 카드). 공통 규약은 `posterModel`/`posterFlow` — 블록 높이를 재고 남는 높이를 `gap(flex)`에 비례 배분하는 `space-between` 방식이라, 프로그램이 1줄이면 여백이 늘고 8줄이면 자동으로 0.58배까지 축소됩니다. 곡명은 칸 폭에 맞춰 폰트를 줄이고 그래도 넘치면 2줄로 접어 겹침·잘림을 막습니다. `state.lastLayout.info`에 `{programRows, programFit, titleLines, noteLines, textWidth, textBudget}`를 돌려줘 테스트가 잘림을 검사합니다. 스타일 선택은 `lessoncard.recitalStyle.v1`에 저장되고, 테마(`THEMES`)와 분리돼 있어 레슨 노트 테마를 바꿔도 팜플렛은 영향이 없습니다.
- **세트별 장식은 캔버스 벡터**: 음표·별·하트·구름·리본·마스킹 테이프·다이아 장식은 이모지나 이미지가 아니라 `drawMusicNotes`·`drawStar`·`drawHeart`·`drawCloud`·`drawTape`·`drawDiamond`로 직접 그립니다. 그래서 PNG로 내보내도 장식이 흐려지거나 빠지지 않고, 글꼴/이모지 렌더링 차이도 없습니다.
- **자간**: 한글은 canvas `letterSpacing` 지원이 브라우저마다 달라, 글자 단위로 직접 배치해 어디서나 동일하게 보이도록 했습니다.
- **반응형**: 1000px 이하에서 1열 + 미리보기 우선 배치 + 하단 고정 저장 바.
- **저장 키(localStorage)**: `lessoncard.draft.v1`(작성 중 폼) · `lessoncard.students.v1`(학생별 최근 기록 배열) · `lessoncard.logo.v1`(로고 DataURL·파일명) · `lessoncard.theme.v1`(선택한 테마) · `lessoncard.themeset.v1`(마지막 세트 탭) · `lessoncard.recitalStyle.v1`(발표회 팜플렛 스타일 4종 중 선택) · `lessoncard.subject.v1`(잘한 점 과목·악기 탭) · `lessoncard.usage.v1`. 학생 기록은 이름 기준으로 최신 1건을 교체 저장하고 목록은 최근 저장순으로 정렬합니다. 세트 탭은 세트별 마지막 테마를 메모리에 기억해 오갈 때 되살립니다.
- **과목 탭**: `SUBJECTS` 배열(피아노·보컬·성악·현악·관악·공통·예체능, 각 8개 프리셋)이 유일한 출처이고, `renderChips()`가 현재 탭 프리셋 + 이미 선택된 태그를 합쳐 그립니다. 그래서 탭을 바꿔도 고른 태그가 사라지지 않고 최대 4개 규칙도 그대로입니다.
- **한마디 문구**: `NOTE_PRESETS` 배열에서 칩을 만들고, 클릭 시 `textarea` 값을 교체한 뒤 `syncCounters()` · `scheduleRender(true)` · `saveDraft()`를 직접 호출합니다. 입력란을 직접 고치면 `input` 이벤트가 칩 강조를 풀어 줍니다.
- **로고**: 업로드 시 `<canvas>`로 긴 변 420px까지 줄여 PNG DataURL로 저장 → 카드에서는 헤더 높이에 맞춰 비율 유지 `drawImage`(모서리 7px 라운드 클립). 로컬 DataURL이라 `toBlob`/`toDataURL`이 막히지 않습니다.
